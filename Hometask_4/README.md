# Домашнее задание 4

## Задачи и соответствия LeetCode

1. Построение бинарного дерева из массива. Точного аналога LeetCode с таким входом нет. В `buildTree(values)` массив трактуется как представление с индексами полного бинарного дерева: для элемента `i` дети находятся на позициях `2*i+1` и `2*i+2`; `None` означает отсутствующий узел. Позиции нужно сохранять, включая `None`.
2. Проверка симметрии бинарного дерева — [LeetCode 101: Symmetric Tree](https://leetcode.com/problems/symmetric-tree/). Метод `isSymmetric(root)`.
3. Минимальная глубина бинарного дерева — [LeetCode 111: Minimum Depth of Binary Tree](https://leetcode.com/problems/minimum-depth-of-binary-tree/). Метод `minDepth(root)`.
4. Произведение минимального и максимального значений BST, заданного массивом. Точного аналога LeetCode нет. `minMaxProduct(values)` использует тот же индексный формат массива, что и задача 1; `None` обозначает пропуск позиции.
5. Проверка идентичности двух бинарных деревьев — [LeetCode 100: Same Tree](https://leetcode.com/problems/same-tree/). Метод `isSameTree(p, q)`.
