# Домашнее задание 2

Файлы №1.py–№8.py содержат только заготовки методов. Решения задач автор добавляет самостоятельно.

## Задачи

1. reverseList — развернуть односвязный список (LeetCode 206).
2. middleNode — найти середину списка (LeetCode 876; для чётной длины возвращается вторая середина).
3. removeElements — удалить из списка узлы со значением val (LeetCode 203).
4. isSubsequence — проверить, является ли s подпоследовательностью t (LeetCode 392).
5. twoSum — найти пару в отсортированном массиве (формат LeetCode 167: вернуть индексы с нумерацией от 1).
6. isPalindrome — проверить палиндром без учёта регистра и не буквенно-цифровых символов (LeetCode 125).
7. removeDuplicates — удалить дубликаты из отсортированного массива (LeetCode 26).
8. mergeTwoLists — слить два отсортированных односвязных списка (LeetCode 21).
