# Домашнее задание 3

Файлы №1.py–№6.py содержат только заготовки методов. Решения задач автор добавляет самостоятельно.

## Задачи и ссылки

1. mySqrt — найти целую часть квадратного корня числа (LeetCode 69: [Sqrt(x)](https://leetcode.com/problems/sqrtx/)).
2. minimumTime — найти минимальное время для копирования N листов двумя ксероксами. Первый экземпляр делает более быстрый ксерокс; затем оба могут копировать параллельно. Близкая задача на бинарный поиск: [LeetCode 2187 — Minimum Time to Complete Trips](https://leetcode.com/problems/minimum-time-to-complete-trips/); модель копирования отличается.
3. findContentChildren — накормить максимальное число животных порциями (LeetCode 455: [Assign Cookies](https://leetcode.com/problems/assign-cookies/)).
4. findTheDifference — найти добавленный символ после перемешивания строки (LeetCode 389: [Find the Difference](https://leetcode.com/problems/find-the-difference/)).
5. twoSum — найти индексы двух элементов с суммой target; если пары нет, вернуть пустой список (LeetCode 1: [Two Sum](https://leetcode.com/problems/two-sum/)).
6. groupAnagrams — сгруппировать анаграммы; порядок групп и слов внутри группы не важен (LeetCode 49: [Group Anagrams](https://leetcode.com/problems/group-anagrams/)).

## Тесты

Из корня репозитория запустить:

python -m pytest Hometask_3/tests

Первый аплоад файлов-заготовок и тестов может быть сделан для удобства нейросетью. Нейросети для решения задач нигде не используются.
