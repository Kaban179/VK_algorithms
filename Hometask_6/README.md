# Домашнее задание 6

## Задачи и ссылки

1. Длина самой длинной непрерывной строго возрастающей подпоследовательности массива — [LeetCode 674: Longest Continuous Increasing Subsequence](https://leetcode.com/problems/longest-continuous-increasing-subsequence/). Метод `findLengthOfLCIS(nums)`.
2. Первые `numRows` строк треугольника Паскаля — [LeetCode 118: Pascal's Triangle](https://leetcode.com/problems/pascals-triangle/). Метод `generate(numRows)`.
3. Минимальное число монет для заданной суммы или `-1`, если сумму нельзя набрать — [LeetCode 322: Coin Change](https://leetcode.com/problems/coin-change/). Метод `coinChange(coins, amount)`.
4. Самая длинная подстрока-палиндром — [LeetCode 5: Longest Palindromic Substring](https://leetcode.com/problems/longest-palindromic-substring/). Метод `longestPalindrome(s)`.
